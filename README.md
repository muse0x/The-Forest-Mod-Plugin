# The Forest — Mod Plugins

Lightweight quality-of-life and utility plugins for **The Forest** (built for BepInEx 5).

## Plugins

| Plugin | Description | Status |
| :--- | :--- | :--- |
| **[FullBright](./FullBright)** | Standalone cave lighting, gamma lift & fog suppressor | :white_check_mark: Ready |
| **FpsBoost** | Renderer optimizer & potato mode | :hourglass_flowing_sand: Coming soon |
| **Cheats & ESP** | In-game inspector & sandbox utility | :hourglass_flowing_sand: Coming soon |

## Quick Install
1. Install [BepInEx 5 (64-bit)](https://github.com/BepInEx/BepInEx/releases).
2. Download any mod `.dll` from its folder `/Release` or the Releases tab.
3. Drop the `.dll` into:
   ```
   The Forest/BepInEx/plugins/
   ```
4. Start the game.
