# the forest — plugins

just a collection of lightweight, standalone quality-of-life mods for the forest. no bloat, no complex setup, just drop in and play. built on bepinex 5.

### mods
- **[fullbright](./FullBright)** — see in the dark without torches. boosts cave ambient, tunes sunlight, kills distance fog. *(ready)*
- **fps boost** — potato mode, removes laggy foliage particles & drops heavy graphics settings. *(wip)*
- **ch34ts & esp** — infinite stamina, swing speed, mob hp overlay & item esp for sandbox fun. *(wip)*

### install
1. get [BepInEx 5](https://github.com/BepInEx/BepInEx/releases) (64-bit) if you don't have it
2. grab whichever mod `.dll` you need (from its `/Release` folder or the Releases tab)
3. drop it into:
   ```
   The Forest/BepInEx/plugins/
   ```
4. launch game. that's literally it.

### notes
- each mod is standalone. pick what you want, leave what you don't.
- everything is open source, build with `dotnet build -c Release`.
